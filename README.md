# DAUD

DAUD is a modern and responsive running footwear e-commerce website.

## Features

- Responsive navigation
- Product search
- Product filtering
- Shopping cart counter
- Wishlist interaction
- Newsletter subscription UI
- Responsive design for mobile, tablet and desktop
- Accessible navigation and interactive elements

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## How to Run Locally

1. Clone the repository:

   git clone https://github.com/MariaNathaliaAmbrose/DAUD.git

2. Open the project folder.

3. Open `index.html` in a web browser.

Alternatively, the project can be opened using the Live Server extension in VS Code.

## Deployment

The website is deployed using [Netlify/Vercel].
